✅ Hướng Dẫn Chi Tiết Chạy CTOOL (Python 3.12)

1. Termux (Android)

Môi trường terminal trên Android. Đảm bảo bạn đã cài đặt Python.

Bước 1: Cài đặt Termux

Tải Termux **Tại đây**, sau đó cài đặt nó.

Bước 2: Cài đặt Python và các thư viện cần thiết

Chạy lần lượt các lệnh sau để cập nhật hệ thống và cài đặt Python, Git cùng các thư viện cơ bản:

Lưu ý: Đôi khi nó sẽ hỏi bạn các câu hỏi (y/n) hãy luôn chọn y

pkg update && pkg upgrade -y
pkg install python git -y
pip install requests colorama rich pycurl

Bước 3: Tải CTOOL

Nhập lệnh sau để tải tool:

curl -o CTOOL.py https://raw.githubusercontent.com/C-Dev7929/Tools/refs/heads/main/main.py

Bước 4: Chạy CTOOL

Nhập lệnh sau để chạy tool:

python CTOOL.py

2. Google Cloud Shell (Cloud/VPS)

Môi trường Linux trên Cloud. Bạn có thể truy cập **Google Cloud Shell tại đây**. Sử dụng `python3` và `pip3` để đảm bảo chạy phiên bản Python mới nhất.

Bước 1: Tải CTOOL

curl -o CTOOL.py https://raw.githubusercontent.com/C-Dev7929/Tools/refs/heads/main/main.py

Bước 2: Cài đặt Thư viện và Chạy Tool

Sử dụng `pip3` và `python3`:

pip3 install requests colorama rich pycurl

Bước 3: Chạy nền (Quan trọng)

Để Tool chạy liên tục khi bạn đóng cửa sổ Cloud Shell:

nohup python3 CTOOL.py &

3. Windows/PC

Thực hiện trên Command Prompt (CMD) hoặc PowerShell.

Bước 1: Cài đặt Python 3.12

Tải bản cài đặt mới nhất từ python.org.
Lưu ý quan trọng: BẮT BUỘC TÍCH VÀO ô **"Add python.exe to PATH"** khi cài đặt.

Bước 2: Tải tool

Hãy vào thư mục download, sau đó click chuột vào thanh đường dẫn, sau đó nhập **cmd** và nhấn **enter**. CMD sẽ hiện ra và ở đây hãy nhập lệnh:

curl -o CTOOL.py https://raw.githubusercontent.com/C-Dev7929/Tools/refs/heads/main/main.py

Bước 3: Cài các thư viện cần thiết

Vẫn trong cửa sổ CMD, hãy nhập lệnh:

pip install requests colorama rich pycurl

Bước 4: Chạy tool

Nhập lệnh sau để chạy tool:

python CTOOL.py
